# curso_ebac_frontend

# Testes com Cypress para a Agenda de Contatos

Este projeto consiste em testes automatizados utilizando o framework de testes Cypress 
para verificar as funcionalidades da aplicação de Agenda de Contatos.

## Funcionalidades a serem testadas

`Inclusão de Contato: Verificar se é possível adicionar um novo contato à agenda.`

`Alteração de Contato: Testar a funcionalidade de edição das informações de um contato existente.`

`Remoção de Contato: Validar excluisão um contato da lista.`

## Como executar os testes

Clone este repositório.
Instale as dependências com `npm install`.
Execute os testes com `npm run test`.
